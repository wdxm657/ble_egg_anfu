- 3-设备定义
    - 蛋安抚器
        - 主要电子器件
            - 主控
                - 星宸373 64MB，19.5RMB
                - 部署声音识别算法
            - 存储
                - XT25F128FWOIGT WSON8 6*5，4.23RMB
            - 麦克风咪头
                - B6050AL-C1033，1.5RMB
            - 超声波模组
                - 双头+板，13.2RMB
            - 扬声器喇叭
                - 1.8RMB
            - 蓝牙芯片
                - EP2T45F10，2RMB
            - 电池
                - 一节18650 EZ，1500 mAh / 3.7V，长寿命 + 低发热
                - 充电时：温度超过50度，停止充电，恢复到40度继续充电
                - 放电时：温度超过70度，停止放电，恢复到60度恢复放电
            - 电源路径管理链路
                - 电源路径管理IC，TP4056，0.3RMB
                - 电源路径开关，一颗 PMOS 做负载开关，AO3401 P-MOSFET，0.1RMB
                - 升降压 DCDC，SGM6601，1.5RMB
                - 说明
                    - 实现
                        - 插电时，一边给电池充电（充满自动停止充电）同时给设备供电
                        - 断电时无缝切换到电池供电
        - 安装要求
            - 摆放在狗狗碰不到的地方，距离地面高度0.7~1.5米，正面无遮挡
        - 功能定义
            - 自动识别吠叫及情绪
                - 7 x 24 小时自动识别狗吠，监测到狗狗持续吠叫则自动执行安抚
                - 每10~15秒为一个监测周期，根据期间识别到的狗吠次数判断是否要执行安抚
                    - 识别叫声情绪
                        - 开心、生气、悲伤、害怕、惊讶
                        - happy、angry、sad、fear、surprised
            - 自动执行安抚
                - 无安抚成功记录时，按照出厂顺序执行安抚，直到狗吠停止或全部措施执行完
                    - 1-播放安抚音乐2分钟
                    - 如果吠叫未停止
                    - 已录制主人声音
                    - 2-播放主人录音
                        - 录音播放次数=ceil(20 / 录音长度)
                    - 如果吠叫未停止
                    - 3-释放超声波5秒
                        - 25kHz@110dB
                    - 如果吠叫未停止
                    - 4-释放超声波5秒
                        - 30kHz@110dB
                    - 如果吠叫未停止
                    - 5-释放超声波5秒
                        - 25kHz&30kHz@110dB
                    - 设备进入60秒休息时间
                - 如果有成功安抚记录，优先执行最近成功的安抚措施
                    - 根据成功安抚记录，基于出厂顺序，调整下次执行顺序
                    - 举例
                        - 最近成功止吠措施
                            - 25kHz@110dB
                        - 下次执行顺序
                            - 1-25kHz@110dB
                            - 2-30kHz@110dB
                            - 3-25kHz&30kHz@110dB
                            - 4-播放安抚音乐
                            - 5-播放主人录音
            - 主人录音管理
                - 录音长度：3~10秒
                - 可在APP控制设备进行
                    - 录音试听
                    - 录音清除
                    - 声音录制
            - 安抚措施可配置
                - 安抚措施可多选，至少选1个
                    - 播放安抚音乐
                    - 播放主人声音
                    - 发射超声波
                        - 发射频率及强度可多选，至少选1个，最多选3个
                            - 25kHz@100dB
                            - 30kHz@80dB
                            - 25kHz&30kHz@100dB
            - 安抚记录查看
                - 可在APP上查看最近30天的安抚记录
            - 恢复出厂
                - 在app上解除配对时，设备恢复出厂状态
                    - 清除主人录音
                    - 安抚措施执行顺序恢复出厂状态
                    - 断开与当前用户的蓝牙连接
            - 首次/长期不使用：通过物理按键开关机
            - 日常：可通过app开关机
        - 数据处理
            - 与APP的数据接口
                - APP请求设备
                    - 配对请求
                    - 解除配对请求
                    - 获取设备状态
                        - 开关状态
                        - 是否存在主人录音
                    - 播放主人录音指令
                    - 删除主人录音指令
                    - 开始录制指令
                    - 结束录制指令
                        - 异常反馈：录音时长<3秒
                    - 对刚录制音频的处理指令
                        - 使用，执行‘播放主人录音’安抚措施时使用此录音
                        - 删除
                    - 音量，请求+指令
                    - 安抚模式，请求+指令
                    - 安抚措施，请求+指令
                - 设备主打上报
                    - 当前工作状态：监测/休息/识别/执行
                    - 安抚记录
                        - 吠叫识别时间
                            - 吠叫时情绪
                        - 安抚措施执行时间（可能多个）
                        - 安抚措施执行后吠叫时的情绪（如果识别到时上报）
                        - 安抚结果及时间
        - 物理UI
            - 物理按钮
                - 开关机：进入/退出低功耗模式，低功耗时蓝牙关闭
            - 指示灯
                - 工作状态灯(蓝/白/绿)
                    - 熄灭：设备已通过按键关机
                    - 白色灯：SOC开机启动中，应该需要在kernel层完成，不在APP完成
                    - 蓝色灯常亮：关机状态，蓝牙连接
                    - 蓝色灯闪烁：关机状态，蓝牙未连接
                    - 绿色灯常亮：开机状态，蓝牙连接
                    - 绿色灯闪烁：开机状态，脸呀未连接
                - 电池状态灯(绿/红)
                    - 绿色闪烁：充电中
                    - 绿色常亮：已充满电
                    - 红色闪烁：电量不足，<15%
            - USB供电口
